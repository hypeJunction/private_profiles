# private_profiles

![Elgg 5.x](https://img.shields.io/badge/Elgg-5.x-orange.svg?style=flat-square)

Restrict profile visibility and private-message permissions site-wide or per user, and let users hide their activity from logged-out visitors.

## Features

- Site-wide and per-user access controls for profile pages (public / logged-in / friends / private).
- Site-wide and per-user controls over who can send a user private messages.
- Per-user toggle to hide activity stream and member listing from logged-out visitors.
- Admin override — admins always retain access regardless of user settings.

## Installation

**Via Composer (recommended):**

```bash
composer require hypejunction/private_profiles
```

**Manual:**

Download the zip, extract into your Elgg `mod/` directory, and activate in the admin panel.

## Compatibility
